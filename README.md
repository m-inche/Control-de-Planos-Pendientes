# Dashboard - Control de Planos Pendientes[cite: 1]

Sistema web interactivo para el monitoreo, control de aprobaciones y gestión de planos pendientes[cite: 1].

## Características Principales
* **Carga de Archivos:** Importación directa de reportes en Excel (`.xlsx`)[cite: 1].
* **KPIs Dinámicos:** Visualización de totales, trámites fuera/dentro de plazo y montos proyectados[cite: 1].
* **Filtros Interconectados:** Segmentación por departamento, contratista, responsable y condición de plazo[cite: 1].
* **Gráficos Estadísticos:** Análisis visual mediante Chart.js (cumplimiento por área, contratistas y costos)[cite: 1].
* **Tablas Operativas:** Tablas con búsqueda en tiempo real, ordenamiento y columnas redimensionables[cite: 1].

## Tecnologías Utilizadas
* HTML5 / Tailwind CSS[cite: 1]
* JavaScript (ES6+)[cite: 1]
* Chart.js & Chart.js DataLabels[cite: 1]
* SheetJS (xlsx)[cite: 1]
* Lucide Icons[cite: 1]
